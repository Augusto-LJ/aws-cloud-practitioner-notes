# 🪣 S3 (Simple Storage Service)

## 📌 O que é

O S3 (Simple Storage Service) é um serviço de armazenamento de **objetos** da AWS.

Ele permite armazenar e recuperar qualquer quantidade de dados de forma altamente escalável, segura e durável.

---

## 🎯 Quando usar

- Armazenar arquivos (imagens, vídeos, documentos)
- Backups
- Data lakes
- Hospedagem de sites estáticos
- Distribuição de conteúdo

---

## ⚙️ Como funciona

- Os dados são armazenados como **objetos**
- Cada objeto possui:
  - Conteúdo (arquivo)
  - Metadados
  - Chave única (key)
- Os objetos ficam dentro de **buckets** e cada objeto pode ter no máximo 5 TB

---

## 📦 Conceitos importantes

### 🪣 Bucket
- Container onde os objetos são armazenados
- Nome globalmente único

---

### 📄 Objeto
- Arquivo armazenado no S3
- Identificado por uma chave única (key)

---

### 🗂️ Estrutura
- Não existe diretório real (é uma simulação por prefixos)

---

### 🌐 Acesso
- Pode ser feito via HTTP/HTTPS
- Integração com diversos serviços AWS

---

## 📊 Classes de armazenamento (storage classes)

### 🟢 S3 Standard
- Ideal para dados acessados com frequência
- Alta durabilidade e disponibilidade, baixa latência
- Baixa latência
- Armazena dados em um mínimo de três Zonas de Disponibilidade
- Preço mais alto do que as classes de acesso de baixa frequência

---

### 🔵 S3 Standard-IA (Infrequent Access)
- Ideal para dados acessados com pouca frequência, mas que precisam ter alta disponibilidade para quando necessário
- Preço de armazenamento menor que o do Standard
- Custo maior por acesso/recuperação
- Armazena dados em um mínimo de três Zonas de Disponibilidade

---

### 🟠 S3 One Zone-IA
- Igual ao Standard-IA, mas em apenas uma AZ
- Mais barato, mas menor resiliência

---

### 🟡 S3 Intelligent-Tiering
- Ideal para dados com padrões de acesso desconhecidos ou em alteração
- Move automaticamente entre classes
  - Ex: Se você não acessou um objeto por 30 dias consecutivos, o Amazon S3 o move automaticamente para o nível de acesso pouco frequente (S3 Standard – IA). Se você acessar um objeto no nível de acesso pouco frequente, o Amazon S3 o move automaticamente para o nível de acesso frequente (S3 Standard).

---

### 🧊 S3 Glacier
- Ideal para armazenamento de arquivamento, ou seja, arquivos que você não pretende mexer por durante muito tempo
- Mais barato que as demais classes de armazenamento
- Divididos em 3 tipos:
  - S3 Glacier Instant Retrival
    - Pode recuperar objetos em milissegundos
    - Mais caro entre os três
  - S3 Glacier Flexible Retrival
    - Pode recuperar objetos em 1 minuto ou até 12 horas 
    - Segundo mais caro entre os três
  - S3 Glacier Deep Archive
    - Pode recuperar objetos em 12 horas ou até 48 horas
    - Mais barato entre os três

---

## 💰 Modelo de cobrança

Você paga por:
- Armazenamento (GB)
- Requisições (PUT, GET, etc.)
- Transferência de dados

👉 Classes mais baratas geralmente têm custo maior de acesso

---

## 🔒 Segurança

- Controle via IAM e políticas de bucket
- Criptografia (em repouso e em trânsito)
- Controle de acesso público/privado

---

## ⚖️ Comparações importantes

### S3 vs EBS

| S3 | EBS |
|----|-----|
| Objetos | Blocos |
| Acesso via HTTP | Anexado ao EC2 |
| Altamente escalável | Baixa latência |

---

### S3 vs EFS

| S3 | EFS |
|----|-----|
| Objetos | Arquivos |
| Não é sistema de arquivos real | Estrutura hierárquica |
| Acesso via API | Acesso via NFS |

---

## 🧠 Conceitos importantes para prova

- S3 = armazenamento de objetos
- Dados organizados em buckets
- Alta durabilidade
- Diferentes classes para otimizar custo
- Acesso via internet (HTTP/HTTPS)

---

## ⚠️ Pegadinhas comuns

- S3 não é armazenamento em bloco
- Não possui diretórios reais
- Glacier não é para acesso rápido
- One Zone-IA tem menor redundância

---

## 🔁 Resumo rápido

- S3 = armazenamento de objetos
- Escalável, durável e seguro
- Organizado em buckets
- Possui várias classes para otimizar custo
