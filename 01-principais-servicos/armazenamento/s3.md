# 🪣 S3 (Simple Storage Service)

## 📌 O que é

O S3 (Simple Storage Service) é um serviço de armazenamento de **objetos** da AWS.

Ele permite armazenar e recuperar qualquer quantidade de dados de forma altamente escalável, segura e durável.

---

## 🎯 Quando usar

- Armazenar arquivos (imagens, vídeos, documentos)
- Backups
- Data lakes
- Hospedagem de sites estáticos
- Distribuição de conteúdo

---

## ⚙️ Como funciona

- Os dados são armazenados como **objetos**
- Cada objeto possui:
  - Conteúdo (arquivo)
  - Metadados
  - Chave única (key)
- Os objetos ficam dentro de **buckets**

---

## 📦 Conceitos importantes

### 🪣 Bucket
- Container onde os objetos são armazenados
- Nome globalmente único

---

### 📄 Objeto
- Arquivo armazenado no S3
- Identificado por uma chave única (key)

---

### 🗂️ Estrutura
- Não existe diretório real (é uma simulação por prefixos)

---

### 🌐 Acesso
- Pode ser feito via HTTP/HTTPS
- Integração com diversos serviços AWS

---

## 📊 Classes de armazenamento

### 🟢 S3 Standard
- Alta durabilidade e disponibilidade
- Uso frequente
- Baixa latência

---

### 🟡 S3 Intelligent-Tiering
- Move automaticamente entre classes
- Ideal para padrões de acesso imprevisíveis

---

### 🔵 S3 Standard-IA (Infrequent Access)
- Para dados acessados raramente
- Mais barato que Standard
- Custo maior por acesso

---

### 🟠 S3 One Zone-IA
- Igual ao Standard-IA, mas em apenas uma AZ
- Mais barato
- Menor resiliência

---

### 🧊 S3 Glacier
- Armazenamento de arquivamento
- Muito barato
- Acesso lento (minutos a horas)

---

## 💰 Modelo de cobrança

Você paga por:
- Armazenamento (GB)
- Requisições (PUT, GET, etc.)
- Transferência de dados

👉 Classes mais baratas geralmente têm custo maior de acesso

---

## 🔒 Segurança

- Controle via IAM e políticas de bucket
- Criptografia (em repouso e em trânsito)
- Controle de acesso público/privado

---

## ⚖️ Comparações importantes

### S3 vs EBS

| S3 | EBS |
|----|-----|
| Objetos | Blocos |
| Acesso via HTTP | Anexado ao EC2 |
| Altamente escalável | Baixa latência |

---

### S3 vs EFS

| S3 | EFS |
|----|-----|
| Objetos | Arquivos |
| Não é sistema de arquivos real | Estrutura hierárquica |
| Acesso via API | Acesso via NFS |

---

## 🧠 Conceitos importantes para prova

- S3 = armazenamento de objetos
- Dados organizados em buckets
- Alta durabilidade
- Diferentes classes para otimizar custo
- Acesso via internet (HTTP/HTTPS)

---

## ⚠️ Pegadinhas comuns

- S3 não é armazenamento em bloco
- Não possui diretórios reais
- Glacier não é para acesso rápido
- One Zone-IA tem menor redundância

---

## 🔁 Resumo rápido

- S3 = armazenamento de objetos
- Escalável, durável e seguro
- Organizado em buckets
- Possui várias classes para otimizar custo
