# 🛒 AWS Marketplace

## 📌 O que é

O AWS Marketplace é uma plataforma onde você pode **encontrar, comprar e implementar softwares de terceiros** que rodam na AWS.

Funciona como uma “loja” de soluções prontas para uso na nuvem.

---

## 🎯 Quando usar

- Utilizar softwares prontos sem precisar instalar manualmente
- Acelerar desenvolvimento
- Adotar soluções de parceiros confiáveis
- Simplificar aquisição de ferramentas

---

## ⚙️ Como funciona

- Você escolhe um produto no Marketplace
- Faz a assinatura/compra
- Implementa diretamente na sua conta AWS
- O custo é cobrado junto com sua fatura da AWS

---

- Sistemas operacionais (ex: Linux, Windows)

- Ferramentas de segurança
- Softwares de monitoramento
- Aplicações empresariais
- AMIs (Amazon Machine Images) prontas

---

## 💰 Modelo de cobrança

Pode variar conforme o produto:

- 💳 Pay-as-you-go (por uso)
- 📅 Assinatura mensal ou anual
- 💵 Licença única

👉 Os custos aparecem na fatura da AWS

---

## 🔗 Integração

- Amazon EC2 (uso comum com AMIs)
- AWS Billing (cobrança centralizada)
- AWS Organizations (controle por conta)

---

## 🚀 Benefícios

- Implementação rápida
- Sem necessidade de configuração manual complexa
- Integração com AWS
- Cobrança centralizada
- Grande variedade de soluções

---

## ⚖️ Comparações importantes

### AWS Marketplace vs Instalação manual

| Marketplace | Manual |
|------------|--------|
| Rápido | Mais demorado |
| Pronto para uso | Requer configuração |
| Cobrança integrada | Gestão separada |

---

### AWS Marketplace vs Desenvolver internamente

| Marketplace | Interno |
|------------|--------|
| Mais rápido | Mais controle |
| Menor esforço | Mais flexível |
| Pode ter custo maior | Pode ser mais barato a longo prazo |

---

## 🧠 Conceitos importantes para prova
