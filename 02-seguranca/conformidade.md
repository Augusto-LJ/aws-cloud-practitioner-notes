# 📜 Conformidade na AWS

## 📌 O que é

Conformidade refere-se à capacidade de atender **normas, regulamentações e padrões de segurança** exigidos por órgãos reguladores ou pelo setor da empresa.

Na AWS, existem serviços e recursos que ajudam empresas a **comprovar conformidade e passar por auditorias**.

---

## 🎯 Quando usar

- Empresas com requisitos regulatórios (ex: saúde, financeiro)
- Auditorias de segurança
- Governança de dados
- Compliance corporativo

---

## ⚙️ AWS Artifact

### 📌 O que é

O AWS Artifact é um serviço que fornece **acesso sob demanda a relatórios de segurança, conformidade e contratos da AWS**.

---

### 📦 Componentes principais

#### 📜 AWS Artifact Agreements
- Permite:
  - Visualizar contratos
  - Aceitar acordos
  - Gerenciar contratos

- Pode ser aplicado para:
  - Conta individual
  - Todas as contas no AWS Organizations

- Exemplo:
  - Acordos relacionados a regulamentações como **HIPAA**

---

#### 📄 AWS Artifact Reports
- Fornece relatórios de auditoria da AWS
- Criados por **auditores independentes**

- Comprova que a AWS está em conformidade com padrões como:
  - ISO
  - PCI-DSS
  - SOC

---

### 🧠 Importante

- Os relatórios podem ser usados como evidência em auditorias
- Sempre atualizados com versões mais recentes

---

## 🏛️ Tipos de conformidade suportados

A AWS atende diversos padrões globais, como:

- ISO (segurança da informação)
- PCI-DSS (dados de cartão de crédito)
- SOC (controles organizacionais)
- Regulamentações específicas de setores

## 🔒 Responsabilidade compartilhada

- AWS é responsável por:
  - Segurança **da nuvem**
- Cliente é responsável por:
  - Segurança **na nuvem**

👉 A conformidade depende de ambos

---

## ⚖️ Comparações importantes

### Artifact vs Auditoria própria

| AWS Artifact | Auditoria própria |
|--------------|------------------|
| Relatórios prontos | Precisa gerar |
| Auditado por terceiros | Interno |
| Rápido acesso | Mais demorado |

---

## 🧠 Conceitos importantes para prova

- AWS Artifact = relatórios de conformidade
- Agreements = contratos
- Reports = auditorias
- Base para auditorias e compliance
- AWS já é certificada em vários padrões

---

## ⚠️ Pegadinhas comuns

- AWS não garante conformidade total sozinho
- Cliente também é responsável
- Artifact não executa auditoria (fornece relatórios)
- Não confundir com ferramentas de segurança ativa
