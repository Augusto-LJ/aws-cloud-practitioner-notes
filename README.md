# ☁️ AWS Cloud Practitioner (CLF-C02) - Resumo dos conteúdos

## 🎯 Objetivo

Este repositório foi criado para servir como um **guia prático e direto ao ponto** para quem está se preparando para a certificação **AWS Cloud Practitioner (CLF-C02)**.

O foco é reunir **resumos claros, organizados e voltados para a prova**, evitando conteúdo excessivamente teórico ou disperso.

---

## 🚀 Para quem é este repositório

Este material é ideal para:

- Iniciantes em AWS
- Pessoas estudando para a certificação CLF-C02
- Quem quer revisar rapidamente antes da prova
- Desenvolvedores que querem entender os conceitos fundamentais da AWS

---

## ⚠️ Para quem NÃO é

Este repositório **não é indicado** para:

- Quem busca conteúdo avançado ou aprofundado
- Preparação para certificações mais avançadas (Associate/Professional)
- Estudos detalhados de arquitetura em nível técnico profundo

---

## 🤝 Contribuições

Contribuições são muito bem-vindas!

Você pode ajudar com:

- Correções de conteúdo
- Melhorias nos resumos
- Novas comparações
- Ajustes de organização

### 🛠️ Como contribuir

1. Faça um **fork** do repositório
2. Crie uma branch para sua alteração:
   - `git checkout -b minha-melhoria`
3. Faça as alterações
4. Commit:
   - `git commit -m "feat: melhora explicação de SQS"`
5. Envie para o seu fork:
   - `git push origin minha-melhoria`
6. Abra um **Pull Request**

### 📌 Boas práticas

- Siga o padrão dos arquivos existentes
- Mantenha o conteúdo direto ao ponto (foco na prova)
- Evite textos muito longos
- Use emojis e estrutura consistente
- Se não tiver certeza sobre algo, pode abrir uma **issue** também 🙂
