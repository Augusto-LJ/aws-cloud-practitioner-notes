# ⚖️ Aurora vs RDS

## 🔗 Referências

- [RDS](../../01-principais-servicos/banco-de-dados/rds.md)

---

## 📌 Diferença principal (resumo rápido)

- **Aurora** → Banco relacional otimizado pela AWS
- **RDS** → Serviço gerenciado de bancos tradicionais

---

## ⚖️ Comparação direta

| Aurora | RDS |
|--------|-----|
| Alta performance | Performance padrão |
| Mais caro | Mais barato |
| Compatível com MySQL/PostgreSQL | Vários engines |
| Escala melhor | Escala limitada |

---

## 🎯 Quando usar cada um

### Aurora
- Alta performance
- Aplicações críticas
- Escalabilidade maior

---

### RDS
- Aplicações comuns
- Custo menor
- Uso tradicional de banco

---

## 🧠 Pegadinhas de prova

- Aurora é parte do RDS (não separado)
- Aurora é mais performático
- Nem todo RDS é Aurora

---

## 🔁 Resumo em 1 linha

- **Aurora = versão otimizada**
- **RDS = serviço geral**
