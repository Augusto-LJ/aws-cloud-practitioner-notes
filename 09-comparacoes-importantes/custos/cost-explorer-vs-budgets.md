# ⚖️ Cost Explorer vs AWS Budgets

## 🔗 Referências

- [Cost Explorer](../../03-custos-e-faturamento/cost-explorer.md)
- [AWS Budgets](../../03-custos-e-faturamento/aws-budgets.md)

---

## 📌 Diferença principal (resumo rápido)

- **Cost Explorer** → Análise de custos
- **AWS Budgets** → Monitoramento com alertas

---

## ⚖️ Comparação direta

| Cost Explorer | AWS Budgets |
|---------------|-------------|
| Análise de custos | Controle de gastos |
| Visualização histórica | Define limites |
| Gráficos e relatórios | Alertas |
| Previsão de custos | Notificações |

---

## 🎯 Quando usar cada um

### Cost Explorer
- Entender gastos
- Identificar padrões
- Analisar uso

---

### AWS Budgets
- Definir limites
- Receber alertas
- Controlar orçamento

---

## 🧠 Pegadinhas de prova

- Cost Explorer não envia alertas
- Budgets não faz análise profunda
- São complementares

---

## 🔁 Resumo em 1 linha

- **Cost Explorer = análise**
- **Budgets = alerta**
